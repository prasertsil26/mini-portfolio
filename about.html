การศึกษา

ปริญญาตรี สาขาวิศวกรรมซอฟต์แวร์

คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏนครปฐม (กำลังศึกษา)

วิชาที่เกี่ยวข้อง: การออกแบบและพัฒนาเว็บเพจเบื้องต้น

เป้าหมาย

  1. ฝึกงานในตำแหน่ง Front-end Developer เพื่อเรียนรู้การทำงานจริง
  2. พัฒนาทักษะ JavaScript และเฟรมเวิร์กสมัยใหม่
  3. สร้างผลงานที่ใช้งานได้จริงและนำไปเผยแพร่บน GitHub
